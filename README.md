# うろぼえ

**「メモを不要にするメモ帳」**（キャッチフレーズ・2026-11-16 本人決定）
覚えたいものだけ残る、消えていくメモアプリ（Android）。
書いたメモは忘却曲線に合わせて上部に再浮上し、「暗記する」を押したものだけが定着の間隔反復へ進む。押さなかったものは30日で消え、7日間だけ「余韻」から復活できる。

- 仕様の正本：`docs/SPEC.md`（v1.0）
- アート方針：`docs/ART_DIRECTION.md` / UIカタログ：`docs/UI_CATALOG.md`
- 技術：Kotlin + Jetpack Compose。保存は端末内ファイル（JSON、データモデルは仕様§7準拠）。外部通信なし、権限要求なし。
- ビルド（このVM専用の事情は build.sh のコメント参照）：`./build.sh assembleDebug`
- バージョン：0.3.10（versionCode 13）、applicationId `app.uroboe`。v0.3.10はポジショニング（「『いつかやろう』を『そろそろやろう』に変える」）を About とホーム空状態に配置し、オンボーディングにタイプ選択ページ（よく忘れる／マルチタスクが苦手／期限に追われたくない→「あなたに最適です」と返す）を追加。v0.3.9は本人の指示でメモを開く画面を作り替え：「メモの詳細」ダイアログを廃止し書く画面と同じ全画面にし、下部に［残す］［今すぐ消す］を固定表示。あわせて保存ボタンを廃止して入力のたびに自動保存し、開いている間の編集を戻せる［戻す］ボタンを追加。v0.3.8は安定性の厳格レビュー（docs/STABILITY_REVIEW_2026-11-16.md）の修正版：連打による二重処理（定着チェックの回答・保存・［残す］・オンボーディングのページ送り）を全経路で防止し、壊れた保存データの読み込み正規化と誤認防止、書き出しの生成元、保存失敗時の復旧順序を改善（見た目の変更なし）。v0.3.7はキャッチフレーズ「メモを不要にするメモ帳」を About 冒頭とオンボーディング1枚目に配置。v0.3.6は画面遷移の厳格レビュー（docs/TRANSITION_REVIEW_2026-11-16.md）の修正版：戻る操作を受け取る仕組みが無く書く画面・使い方画面で戻るとアプリが終了していた問題を修正（戻るでホームへ／前ページへ）、編集中・入力中の破棄確認と、回転・再生成での状態保持を追加。v0.3.5は本人の実機FB：書く画面をGoogle Keep風の枠なしに作り替え（上部は戻ると保存だけ・自動フォーカス・クイズ切替はチップ化）、ホーム空状態を薄れモチーフ＋短文に変更、フッターの横はみ出し回帰を縦並びで修正。v0.3.4はUX見直し第2回（docs/UX_REVIEW_v0.3.3.md）の必須＋推奨全件：再会カードのボタンを［見た］に統合、成果表示を卒業の有無から切り離し、About・初回案内へのアンインストール警告と「データを書き出す」（JSON共有）を追加、仕様§11の検証を段階制に再定義。署名は固定鍵のまま（v0.3.3から上書き更新可）。v0.3.3はデータ消失事故（2026-11-15）への対策版：署名鍵を `.local/uroboe-debug.jks` に固定（既定デバッグ鍵はVM再配置で消えて上書きインストール不可→入れ直しでデータ消失した疑い）、保存ファイルの1世代バックアップ（memos.json.prev）と読込時の自動復旧・原本控えを追加。署名が変わるため v0.3.2 からの移行は1回だけ入れ直しが必要（データは消失済みのため追加の損失なし）。以降の更新は同じ鍵で上書きできる。v0.2でタブを廃止し単一画面化（本人の「もっとシンプルに」指示）。v0.3はUX見直し（docs/UX_REVIEW_v0.2.md）の A+B 全件を実装：重複表示の解消、再会は1日1チェックポイントまで、原子的保存、行タップ詳細ほか。v0.3.1は本人の実機FB：書く画面を全画面化、再会ボタンは「👁見た」、「暗記する」は「残す」に改名、題名「null」バグ修正。v0.3.2は不具合の総点検：ID衝突、日付のタイムゾーン境界、前日の再会残留、読込の堅牢化、復帰時の即時更新、全画面の余白などを修正（見た目の変更なし）。

# うろぼえ

**「『いつかやろう』を『そろそろやろう』に変えるメモ帳」**（Android）

書いたメモは勝手には消えず、すべて1つの一覧に並びます。  
上段（「そろそろやろう」）は忘却曲線に沿って忘れかけたものから順に上へ浮かび上がり、カードを長押しすると出るメニューで「またあとで」や下段（「いつかやればいい」・自動浮上なしの保留）へ分けられます。開いた画面からは「やった」で完了できます。

- 仕様の正本：[docs/SPEC.md](docs/SPEC.md)（v2.0 / v0.4.1 正本）
- アート方針：[docs/ART_DIRECTION.md](docs/ART_DIRECTION.md) / UIカタログ：[docs/UI_CATALOG.md](docs/UI_CATALOG.md)
- 技術：Kotlin + Jetpack Compose。保存は端末内ファイル（JSON）。外部通信なし、権限要求なし。
- ビルド（VM専用の事情は `build.sh` のコメント参照）：`./build.sh assembleDebug`
- バージョン：**0.5.1**（versionCode 19）、applicationId `app.uroboe`。

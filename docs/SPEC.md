## 1. コンセプト

**「いつかやろう」を「そろそろやろう」に変えるメモ帳。**

- 期限を切るほどではない「いつかやろう」「気になりごと」を、分類なしで1行預ける。
- **書いたメモは勝手には消えない**。削除・完了はすべて利用者の明示的操作のみ。
- 忘却曲線に沿って、忘れかけたメモが上段（「そろそろやろう」）の上位へ静かに浮かび上がる。
- 見返す努力はゼロ。開いたときに一番上にあるメモを、右スワイプで「またあとで」、左スワイプで「いつかやればいい」（自動浮上なしの保留）、編集画面の「やった」で完了と軽くさばける。

### ターゲット
- メモは取るが二度と見返さない人、よく忘れる人、マルチタスクが苦手な人、期限に追われたくない人。
- 期限付きの重いタスク管理ではなく、日々の「いつかやろう」を気楽に預けたい人。

### やらないこと（コンセプトを守るための禁止事項）
- フォルダ／タグ／階層分類（分類コストが「とりあえず書く」を殺す）
- 溜めることを前提にした検索の作り込み（現時点では検索なし）
- 通知の連打、ストリーク、ランキング等の罪悪感ギミック
- アカウント／サーバー／同期／自動送信（端末内完結）

## 2. アート方針（要約・詳細は `docs/ART_DIRECTION.md`）

- 世界の言葉：**静か／浮かび上がる／紙の温かさ**
- 背景は紙色 `#FFFBF3`、本文はインク色 `#2B2620`、補助テキストは `#665D51`
- 強い色はピンク `#C2185B` の1点だけ。ぼかして見たときに、FAB「＋」と最上部の「忘れかけ」ハイライトだけが静かに浮かぶこと。
- 警告・削除には赤を使わず、WCAG AA（4.5:1以上）を満たす落ち着いた濃い橙 `#B83B00` を使う。
- 全テキストでコントラスト 4.5:1 以上、最小文字サイズ 12sp 以上を確保する。
- モチーフは「下の2本が静かに控え、上の1本がピンクで浮かび上がる」3本バーに統一する（旧「薄れて消える」モチーフは廃止）。

## 3. メモの状態と行為モデル

```
[書く] → 上段「そろそろやろう」（lowPriority = false, reviewStage = 0）
            ├─ タップ（閲覧・編集）：読む・編集するだけ。忘却ステージは進めない
            ├─ 右スワイプ / 詳細［まだやらない］：節目到達時は次ステージへ進行、未到達時は現在ステージで起点更新
            ├─ 詳細［そろそろやる］：「やる」宣言（willDoAt）を付け、上段の最上部に固定する（v0.4.3）
            ├─ 左スワイプ / 詳細［下段へ］：下段「いつかやればいい」へ保留（lowPriority = true）
            └─ 詳細［やった］：完了として一覧から外す（保護された「元に戻す」バナー付き）※v0.4.2までの［できた］を改名

下段「いつかやればいい」（lowPriority = true、自動浮上なし）
            ├─ タップ（閲覧・編集）
            ├─ 右スワイプ / 詳細［上段へ戻す］：上段へ復帰（reviewStage = 0, 最上部15分維持）
            └─ 左スワイプ / 詳細［削除する］：確認ダイアログ後に完全削除
```

重要な不変ルール：
- **閲覧・編集だけでは忘却ステージを進めない／リセットしない**（誤タップ・誤字修正でメモが沈む・進行が阻害されるのを防ぐ）。
- **上段のスワイプに削除を置かない**。削除は下段左スワイプまたは詳細［削除する］から確認ダイアログを経て実行する。
- **既存クイズ形式メモ（v0.3.x以前で作成）の互換維持**：新規作成は純粋な1欄メモに一本化しつつ、既存のクイズ形式メモは一覧・編集画面で互換閲覧・編集でき、1件も失わない。

## 4. 忘却曲線ソート（上段「そろそろやろう」）

### インターバル（7段階）
`1時間 → 1日 → 3日 → 7日 → 14日 → 30日 → 60日`（stage 0..6）

### 忘却度比率とソート規則
- 忘却度比率：`forgettingRatio = (now - lastReviewedAt) / currentIntervalMs(reviewStage)`
- 1.0 以上で「節目到達（`isDueForReview`）」。
- 上段の並び順（Tier -1 → Tier 0 → Tier 1 → Tier 2）：
  - **Tier -1（「そろそろやる」宣言中：`willDoAt != null`）**：最上部に固定。宣言が新しい順（v0.4.3）。
  - **Tier 0（直後猶予）**：新規作成または上段復帰から15分以内（`enteredActiveAt` 基準、かつ未「またあとで」）→ 新しい順。
  - **Tier 1（節目到達済み：`ratio >= 1.0`）**：`min(forgettingRatio, 2.0)` の降順、同率時は `lastReviewedAt` が古い順（短周期の放置メモが長期メモを押し下げ続ける歪みを防ぐ）。
  - **Tier 2（次の節目待ち）**：`forgettingRatio` の降順（節目に近い順）。
- **「忘れかけ」ピル表示**：Tier 1 のうち**最上位3件まで**に限定し、数十件蓄積時に画面がピンクで埋まるのを防ぐ。

### 下段（「いつかやればいい」）
- `lowPriority == true` のメモを `lowPriorityAt` 降順（新しく保留した順）に表示。
- 自動浮上は行わない（セクション見出しに「自動浮上なし」と明記）。

## 5. 画面仕様

### 5.1 単一画面（ホーム）
- 並び：メモカードは**二列グリッド**（v0.5.2、本人の指示で一列から変更。見出し・バナー・空状態・フッターは全幅、同じ行のカードは高さを揃える）。下段カードは横幅に合わせ題名（最大2行）の下に経過日数を積む
- 本文プレビュー：カードには題名に続けて本文（題名行を除いた残り）も表示する（v0.5.3、本人の指示）。上段は最大3行、下段は最大2行で、題名の下・経過日数の上に置く。クイズ形式メモは下段ではプレビューを出さない
- ヘッダー：アプリ名「うろぼえ」のみ（v0.5で日付と［使い方］を削除。使い方はフッター「その他」→「このアプリについて」内の［使い方を見る］から開く）
- 保存失敗時バナー：万一保存に失敗した場合のみ上部に警告を表示（黙殺しない）。文中の書き出し導線は「その他 → データを書き出す」と明示する
- 空状態：浮上モチーフ＋「まだメモがありません」＋「右下の＋から、『いつかやろう』を1行書いてみて」
- 上段「そろそろやろう」：見出し＋件数（合計のみ。忘れかけ総数は表示しない）。カードは白背景・くっきり表示、右スワイプ「またあとで →」／左スワイプ「↓ いつかやればいいへ」。カードに経過日数は出さず、ピル（そろそろやる／忘れかけ）がある時だけ右上に表示。本文プレビューは1行まで（v0.5）
- 下段「いつかやればいい（自動浮上なし）」：見出し＋件数。§4の「自動浮上なし」明記は見出しに含める。カードは紙馴染みの落ち着いた背景（`#F6F0E4`、不透明度100%でコントラスト確保）、右スワイプ「↑ そろそろやろうへ戻す」／左スワイプ「削除（確認ダイアログ）」
- 下部Undoバナー：FABと干渉しない位置に配置し、`LiveRegionMode.Polite` で読み上げ対応。`MemoStore` 保持により画面回転でも失われない。
- FAB「＋」：書く画面を開く（`contentDescription = "新しいメモを書く"`）
- フッター：［その他］メニューに集約（このアプリについて／データを書き出す／データをすべて消す）（v0.5）

### 5.2 書く画面（全画面）
- 枠なし1欄入力（最大1,000字、900字以上で残り字数表示、長文スクロール対応）。自動フォーカス。
- 上部バー：［←］のみ。説明文は置かない（v0.5）。
- **自動保存**（v0.5.1で［保存］ボタンを廃止）：最初の入力でメモを作成し、以後は入力のたびにその場で保存する。全部消したら作りかけのメモも消える（実質なかったことになる）。戻る操作は確認なしでそのまま確定する。詳細画面の自動保存と方式を統一した。

### 5.3 メモを開く画面（`EditScreen`・全画面）
- 開いた時点では自動フォーカスしない（静かに読める。タップで編集）。
- 入力のたびに自動保存＋［↩ 戻す］（編集履歴最大50件）。「自動で保存されます」の常駐注記は置かず、空文字時の警告だけを後出しで明示する（v0.5）。
- 状態は1行表示：「M月d日 ・ 寝かせ具合」（上段：宣言中／忘れかけています／預けたばかり／次の浮上まで あと◯。下段：「M月d日 ・ いつかやればいい」）（v0.4.3で追加、v0.5で1行化）。
- 下部操作ボタン（360dp幅でも折り返さない短いラベル）：
  - 上段メモ：主ボタン［そろそろやる］［まだやらない］、副ボタン［下段へ］［やった］。宣言中は主ボタンが［やった］［まだやらない］になる（v0.4.3）
  - 下段メモ：［上段へ戻す］［削除する］

### 5.4 オンボーディング（初回4枚・縦スクロール対応）
1. 「書くだけでいい」（コピー：「『いつかやろう』を『そろそろやろう』に」）
2. 「どのタイプに近い？」（3択＋`selectable`＋フェードイン応答、選択は `user_type` へ保存）
3. 「忘れかけた頃、上へ浮かぶ」（勝手には消えないことを明示）
4. 「さばき方は、スワイプひとつ」（右＝またあとで／左＝保留／できたで完了／アンインストールで全消失の警告）
- スキップ確認ダイアログでも「消えずに残ること」と「アンインストールで全消失」を必ず1行届ける。

## 6. データモデル・永続化（端末内JSON）

`memos.json`（`schemaVersion = 2`）：
- `id`, `body`, `question`, `answer`, `createdAt`, `updatedAt`, `lowPriority`, `lowPriorityAt`, `reviewStage`, `lastReviewedAt`, `enteredActiveAt`, `reunions`, `willDoAt`（v0.4.3追加・「そろそろやる」宣言時刻、旧データでは欠落＝nullとして読む）
- **安全な保存**：`memos.json.tmp` へ書き出し＆`fsync` → 既存 `memos.json` を消さずに `memos.json.prev` へコピー → `tmp` を `memos.json` へ置換（`memos.json` 不在ウィンドウを作らない）。
- **自動復旧**：起動時に `memos.json` が不在または破損していたら `memos.json.prev` → `memos.json.tmp` の順で自動復旧する。
- **v0.3.x 自動移行**：`FLOWING`/`LEARNING` は上段（`LEARNING` は `stage + 1` で間隔整合）、`AFTERGLOW`/`MASTERED` は下段へ移行し、1件も失わない。
- **時刻ガードと省I/O**：`MemoStoreHolder`（Applicationスコープ）で保持し、60秒タイマーはフォアグラウンド中のみUI時刻を更新（ディスク保存しない）。

## 7. 受け入れ条件（旧§9 全面改定）

1. メモを作成すると上段「そろそろやろう」の最上部に15分間表示され、勝手には消えない。
2. 編集画面を開く・編集するだけでは `reviewStage` も `lastReviewedAt` も変化しない（画面回転でも発火しない）。
3. 上段の右スワイプまたは編集画面［またあとで］で、節目到達時は次ステージへ進み、未到達時は現在ステージのまま起点更新して Fresh 猶予へ戻らない。
4. 節目到達メモが複数ある場合、`MAX_SORT_RATIO = 2.0` の頭打ちにより、長期放置された高ステージメモが短周期メモに押し下げられ続けない。
5. 「忘れかけ」ピンクピルは節目到達済みの上位最大3件にのみ表示される。
6. 上段の左スワイプ／［下段へ］で「いつかやればいい」へ移動し、下段の右スワイプ／［上段へ戻す］で最上部（Fresh）へ復帰する。
7. 上段の編集画面［やった］で完了し、画面回転しても失われない「元に戻す」バナーから復元できる。
8. 下段の左スワイプおよび［削除する］では確認ダイアログを挟み、誤削除を防止する。
9. `memos.json` 不在・破損時に `memos.json.prev` から自動復旧し、v0.3.x データから全状態が1件も失われず移行される。
10. 狭幅（360dp）＋フォント拡大で編集画面下部ボタン・セクション見出し・オンボーディングが崩れず、全テキストがコントラスト 4.5:1 以上を満たす。

## 8. 検証のしかた（旧§11 全面改定・段階制）

実機・実メモで段階ごとに判定する（AIの確認やビルド成功を体験確認に読み替えない）：

- **第1段階（開始〜1週間）**：
  1. 書く入口が面倒にならない（1行でサッと預けられる）。
  2. 「またあとで（右）」「保留（左）」「できた（完了）」が迷わず・誤削除なく使える。
  3. 1時間〜3日の浮上と上位3件の「忘れかけ」表示が「うるさい」でなく「ちょうどいい」と感じる。
- **第2段階（2週間〜1ヶ月）**：
  4. メモが20〜50件溜まった状態で、上段の視認性と下段（自動浮上なし保留）の分離が破綻しない。
  5. 通知なしで自分から開く習慣が続く。
  6. 「勝手に消えない安心感」のまま、「いつかやろう」が「そろそろやろう」に変わって完了した体験が複数件生まれる。
- 崩れた項目があれば、機能追加の前にソート係数・表示件数・文言の調整で直す。

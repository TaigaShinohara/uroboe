# うろぼえ アート方針 1.0

正本：MVP仕様書（~/workspace/your_files/uroboe-mvp-spec.md）§2。UIを作る／調整する際は毎回ここを参照する。

## 世界の言葉
- 静か／溶ける／紙の温かさ
- やらない雰囲気：にぎやかなゲーミフィケーション、赤い警告、情報の詰め込み

## 色（役割で固定）
| 役割 | 色 | 値 |
|---|---|---|
| 背景（紙） | 紙色 | #FFFBF3 |
| 本文（インク） | インク | #2B2620 |
| 補助テキスト | 薄インク | #6F6659 |
| 罫・区切り | 罫 | #E9DFCF |
| カード | 白 | #FFFFFF |
| 強い色（唯一）＝「暗記する」等、押すべきもの | ピンク | #C2185B |
| 注意（期限が近いときだけ） | オレンジ | #E65100 |
| 定着の進捗 | 紫 | #6A1B9A |

- ぼかして見たときに、押すべきもの（ピンク）が1つだけ浮かぶことが合格条件。
- 赤は使わない。期限は数字で脅さず、文字の薄さ（不透明度）と残りバーで伝える。

## 形・文字・動き
- 角丸：カード16dp、大きな出題カード20dp、ボタンは全丸（999dp）
- 影は弱く（カード1〜2dp）。枠線より余白で分ける
- 動きは「薄れる」「浮かび上がる」など意味のあるものだけ。過剰なアニメーションは入れない

## 根拠
- コンセプト「消えるのがデフォルト、残すのが唯一の能動アクション」→ 強い色はその1アクションにだけ使う。
- 「消えることが怖くない」→ 警告色とカウントダウン演出を排除し、薄れという静かな表現に統一。

## v0.3.6 追記（2026-11-16 画面遷移の厳格レビュー）
- 根本原因：単一Activity＋画面差し替え構成で、戻る操作を受け取る仕組み（BackHandler）が皆無だった。ダイアログでない2画面（書く画面／オンボーディング）では戻るでアプリが終了し、書く画面では下書きも消えていた。
- 書く画面：戻る＝［←］と同じ扱いにしホームへ戻す。入力があるときだけ破棄確認を挟む。
- オンボーディング：戻るで前ページへ／再表示時はホームへ／初回は告知確認へ（スキップと同じ経路に統一）。
- 詳細ダイアログ：未保存の変更があるときだけ、戻る・外側タップ・［閉じる］の全経路で破棄確認を挟む。
- 状態保持：下書き・開いている画面・ページ位置を rememberSaveable 化（回転・再生成対策）。
- 詳細は docs/TRANSITION_REVIEW_2026-11-16.md。署名は固定鍵のまま＝上書き更新可。

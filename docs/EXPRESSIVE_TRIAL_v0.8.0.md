# M3 Expressive 最小試行（v0.8.0）

## 発端
Xポスト 2124961333494124589（Robert Bye／Anthropic PM、2026-11-24）：
Claude モバイルアプリ Android 版が Material 3 Expressive を全面採用したという棚卸しを受け、
本人の了承（2026-11-28、この試行チャット）で、うろぼえに最小範囲だけ試す。

Claude 事例から学んだ型：
- 全面に派手にするのではなく、触る要所（ナビ／シート／スライダー／入力欄）だけ Expressive 化
- ブランド色は自前のまま（Dynamic Color は不採用）＝うろぼえでも Palette（紙・ピンク）は不変
- 弱点も確認済み：予測型バックで「前の画面のプレビュー」が未実装だった → こちらは最初から付ける

## 試行した3要素

### ① 再会カードのボタングループ化
- 対象：「きょうの再会」カードの［そろそろやろうに戻す］［とじる］（従来は TextButton 2つ）
- つながったボタングループ（主＝ピンクベタ／副＝白、内側の角は 4dp、外側 24dp、間隔 2dp、高さ 48dp）
- 押下中：そのボタンが幅 +15% に広がり隣が譲る（スクイーズ、全体幅は不変）、外側の角が 24dp→10dp にモーフ
- 公式 ButtonGroup は material3 1.4 系 alpha のため、1.3 系の基礎部品＋ExpressiveUI の
  実証知見（押下＝形のモーフ／グループのスクイーズ）で再現した
- 動きを減らす設定（アニメーション倍率 0）ではアニメーションなし

### ② 起動ローディングのモーフィング化
- `MorphingLoadingIndicator`：形が円→四角→三角寄り→ひし形→花→楕円→四弁と姿を変え続ける
  （Material の LoadingIndicator の発想。回転と形変化の位相はずらす）
- 出し方：起動時に初回フレームが 120ms 以内に描けなければ表示（遅延表示＝チラつき防止）。
  人工的な待ち時間は足していないので、通常の起動ではほぼ見えないのが正しい状態
- 動きを減らす設定では静止した円

### ③ 編集画面の予測型バック
- `android:enableOnBackInvokedCallback="true"`（マニフェスト）＋ activity-compose 1.10.1 の
  `PredictiveBackHandler` を編集画面に適用
- 戻るジェスチャの進捗に合わせて編集画面が最大 6% 縮小＋薄くなる＝前の画面（ホーム）が
  うっすら見えるプレビュー側の動き。指を戻してキャンセルすれば画面も戻る
- API 33 以下では通常の戻る操作として動作

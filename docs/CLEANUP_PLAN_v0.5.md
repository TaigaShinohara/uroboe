# うろぼえ 整理計画 v0.5（2026-11-22）

コンセプトを軸に、ノイズを削って「きれいにコンパクト」にするための計画。
対象は現行 v0.4.3（MainActivity 1,401行）。本書は計画であり、実装は本人の承認後。

## 判断軸（コンセプト）

- 「メモを不要にするメモ帳」／「『いつかやろう』を『そろそろやろう』に変える」
- 核のループは4つだけ：**①1行預ける → ②忘れかけに浮かぶ → ③そろそろやる／まだやらないを選ぶ → ④やったで消える**
- このループに直接役立たない要素は、原則としてノイズとして扱う。
- 物差し：「読まなくても分かるか。3秒で次にすることが分かるか」（情報最小化スキル）

## 独立審査への対応（2026-11-22、必須3件・推奨3件・観察5件）

- **R-1（必須）書き出すへの案内文**：About文は「その他 → データを書き出す」に書き換え済み。保存失敗バナーも同じ導線に書き換えた。
- **R-2（必須）使い方の統合方式**：方式は **(a) About内に「使い方を見る」入口を置き、オンボーディング再表示を維持**する。到達は「その他 → このアプリについて → 使い方を見る」の3タップ（最下部までのスクロールを除く）を検証条件に加える。
- **R-3（必須）フォント対応表**：特大24／見出し17／本文15／補助12.5 の4段＋例外1種で確定。
  - 26（オンボーディング見出し）→ 24／24（アプリ名）→ 24 据え置き
  - 18・17・16.5 → 17（入力フィールドの17は「書く文字が主役」として見出し段に据え置き）
  - 16・15.5・15 → 15
  - 14.5・14・13.5・13・12.5・12 → 12.5（操作ボタンのラベルも含む。ボタンは形と太字で階層を保つ）
  - 例外：20（「←」戻るグリフ）は文字階層ではなく記号の視認性として据え置き
- **R-4（推奨）初見フォロー**：「初回だけ出す」案を見た上で本人が両方消すと決めた経緯を踏まえ、**初見フォローなしを意図的なリスク受容として明記**する。詳細画面に全操作ボタンがあるため機能への到達は保たれる。
- **R-5（推奨）「自動浮上なし」の明記**：ヒント文は消すが、下段見出しを「いつかやればいい（自動浮上なし）」とし、役割の明記（SPEC §4）は見出し側に残す。
- **R-6（推奨）「その他」の形式と到達**：形式はドロップダウンメニューで確定。到達は「最下部までスクロール → その他 → 項目」の2タップ（従来も最下部＋1タップであり、増分は1タップ）。
- **R-7（観察）件数の根拠訂正**：根拠は「ピルで分かる」ではなく「**忘れかけ総数は表示しない（ピルは最大3件まで）という意図的な情報削減**」と正確に記す。
- **R-8（観察）状態行の形**：上段・未宣言＝「M月d日 ・ 忘れかけています」等／宣言中＝「M月d日 ・ 『そろそろやろう』に決めたメモ」（長い場合は折り返し可）／下段＝「M月d日 ・ いつかやればいい」。西暦なしは年跨ぎで曖昧になる点を受容する。
- **R-9（観察）自動保存の伝達**：受容（空の警告の後出しは残る）。
- **R-10（観察）SPEC改訂**：実装と同作業で SPEC §4・§5.1・§5.2・§5.3 を改訂する。
- **R-11（観察）検証の分け方**：検証報告は「要素削除（導線）」と「フォント（見た目）」の変更群ごとに分けて記録する。

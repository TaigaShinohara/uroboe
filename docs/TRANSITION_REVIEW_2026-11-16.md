# うろぼえ 画面遷移レビュー（2026-11-16・本人の厳格レビュー指示）

症状（本人）：遷移先の画面で「戻る」操作をすると、アプリが終了してしまうことがある。
対象：v0.3.5 → 修正版 v0.3.6（versionCode 9）

## 根本原因
アプリは単一Activity＋状態による画面差し替え構成で、戻る操作を受け取る仕組み（BackHandler）が全画面を通じて皆無だった。ダイアログは戻るで閉じるが、画面差し替えで表示される2画面（書く画面／オンボーディング）は戻るを受け取る者がいないため、Activityが終了しアプリが落ちていた。書く画面では下書きも同時に失われていた。

## 棚卸し結果（全遷移パターン）
| 画面・遷移 | 戻る挙動（修正前） | 判定 |
|---|---|---|
| ホーム | アプリ終了 | 正常（Android標準） |
| 書く画面（＋から） | **アプリ終了＋下書き消失** | 不具合 → 修正 |
| 使い方（オンボーディング再表示） | **アプリ終了**（ホームへ帰れない） | 不具合 → 修正 |
| オンボーディング初回 | アプリ終了。加えて戻るが「30日で消える」告知確認をすり抜ける経路だった | 不具合 → 修正 |
| 詳細ダイアログ | 閉じる（ただし編集中の変更が無言で消える） | 改善 → 修正 |
| About／削除確認／全削除確認／スキップ告知 | 閉じる（キャンセル扱い） | 正常 |
| 画面回転・再生成 | 開いている画面と下書きが初期化される（remember のみで保持なし） | 不具合 → 修正 |

## 修正（v0.3.6）
1. 書く画面：BackHandler を追加。戻る＝画面内［←］と同じ扱いになり、ホームへ戻る。書いたものがある場合は「破棄しますか？」の確認を挟む（空なら即戻る）。
2. オンボーディング：BackHandler を追加。途中ページでは前のページへ戻る。1枚目では、再表示（使い方）ならホームへ帰り、初回ならスキップ時と同じ告知確認を出す（告知の抜け道を塞いだ）。告知ダイアログ表示中はハンドラを無効化し、ダイアログ側の戻る処理に任せる。
3. 詳細ダイアログ：戻る／外側タップ／［閉じる］の全経路で、未保存の変更がある場合のみ破棄確認を挟む（Dialog の onDismissRequest に統一）。変更がなければ従来どおり即閉じ。
4. 状態保持：書く画面の下書き（本文・質問・答え・クイズ切替）、開いている画面（書く画面／詳細）、オンボーディングのページ位置を rememberSaveable 化し、回転・再生成でも消えないようにした。

## 検証
- ビルド成功（BUILD SUCCESSFUL、gradle_exit=0）。証明書は固定鍵 45a1440c… で従来版と同一＝上書き更新可。
- 戻る挙動の実機確認は本人の操作待ち（コード上の経路は全遷移について確認済み）。特に書く画面での戻る（ジェスチャー／ボタン両方）と、回転時の下書き保持を見てもらう。
